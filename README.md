# 🎯 Prospective Customer Segmentation

A modern customer segmentation interface built with **React.js** and **Tailwind CSS**.

This project is a frontend UI implementation focused on creating a clean, modern and component-based digital banking experience. The interface presents different customer segments using reusable React components, props and a horizontally scrollable card layout.

## 🧠 React Concepts Used

This project was created to practice and demonstrate important React concepts.

### 1. Component-Based Architecture

The UI is divided into smaller reusable components instead of building the entire interface inside one component.

### 2. Props
   
The customer cards are designed to be reusable by passing different data through props.

### 3. Reusable Components

Instead of creating separate HTML structures for every customer segment, reusable components are used.

### 4. Tailwind CSS

Tailwind CSS utility classes are used throughout the project for:

Flexbox layouts
Width and height
Spacing
Typography
Backgrounds
Border radius
Positioning
Overflow
Horizontal scrolling
Responsive styling
